Llanquihue Tour App
Autor
Cristóbal Silva Leiva

Descripción
Sistema desarrollado en Java utilizando Programación Orientada a Objetos, colecciones y lectura de archivos Excel mediante Apache POI.

La aplicación permite cargar información de tours turísticos desde un archivo Excel (.xlsx), almacenarla en una colección dinámica y realizar búsquedas y filtros por distintos criterios.

Estructura de paquetes
model

Tour.java
Ubicacion.java
data

GestorTours.java
ui

Main.java
Funcionalidades
Lectura de datos desde Excel (.xlsx)
Uso de colecciones ArrayList
Composición entre clases
Búsqueda por tipo de tour
Filtrado por precio
Visualización de resultados en consola
Tecnologías utilizadas
Java
Maven
Apache POI
Excel (.xlsx)
Ejecución
Abrir el proyecto en IntelliJ IDEA.
Permitir que Maven cargue las dependencias.
Ejecutar la clase Main.java ubicada en el paquete ui.
Revisar los resultados en consola.
